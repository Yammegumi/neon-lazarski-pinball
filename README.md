# 🎰 Neon Pinball

An arcade-style neon pinball game that runs in the browser.
Built with TypeScript, the HTML5 Canvas API, and a custom 2D physics engine.

> Final project for **AI and Data Analysis II** — instructor **Wojciech Drab**.

**Authors:** Mateusz Laski · Mateusz Szuba · Oliwa Regulska · Szymon Szczygielski

![status](https://img.shields.io/badge/status-MVP%20complete-39ff14)

## 🕹️ About

Neon Pinball is a synthwave-themed pinball game. Launch the ball, work the
flippers, and rack up points off glowing bumpers, targets, and slingshots —
all rendered with real-time light effects on the HTML5 Canvas.

## 🛠️ Tech Stack

- **TypeScript** — typed, maintainable game logic
- **HTML5 Canvas API** — rendering + custom physics (no game framework)
- **Vite** — dev server & build tool
- **LocalStorage** — persistent best score
- **Web Audio / HTML5 Audio** — sound effects (CC0 samples)
- **GitHub Pages** — hosting

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Install
```bash
git clone https://github.com/<your-username>/neon-lazarski-pinball.git
cd neon-lazarski-pinball
npm install
```

### Run locally (dev server)
```bash
npm run dev
```
Then open the printed URL (usually http://localhost:5173).

### Build for production
```bash
npm run build
```
Output is generated in the `dist/` folder.

### Preview the production build
```bash
npm run preview
```

## 🌐 Deploy to GitHub Pages

This repo deploys automatically via GitHub Actions on every push to `main`.

1. Confirm `base: '/neon-lazarski-pinball/'` in `vite.config.ts` (matches the repo name).
2. Push to `main`.
3. In GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. The game will be live at:
   `https://<your-username>.github.io/neon-lazarski-pinball/`

## 📁 Project Structure

```
src/
├─ main.ts          # Entry point — sets up canvas, starts the loop
├─ style.css        # Page + (later) HUD/screen styling
├─ core/            # Game loop, state machine, input
├─ physics/         # Vector math + collision detection (later stages)
├─ entities/        # Ball, flippers, bumpers, targets… (later stages)
├─ board/           # Board layout (later stages)
├─ systems/         # Score, lives, audio, storage (later stages)
├─ ui/              # Rendering helpers, HUD, screens
└─ config/          # All tunable gameplay values
```

## 🔊 Sound

The sound effects in `public/sounds/` are short, royalty-free (CC0) blips
**generated by `scripts/generate-sounds.mjs`** (simple Web-Audio-style
synthesis written to `.wav`). Regenerate them anytime with:

```bash
node scripts/generate-sounds.mjs
```

To use richer audio, replace any file in `public/sounds/` with a CC0 sample
of the **same filename** (e.g. from [kenney.nl](https://kenney.nl/assets?q=audio)) —
no code changes needed. Background music is optional and not included.
